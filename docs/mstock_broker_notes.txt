MStock Broker Integration - Implementation Notes

This notes the addition of mstock broker type to the DegenView fork.

## Current Status
- mstock broker type NOT currently in the codebase
- Existing broker infrastructure uses `degenview-brokers` crate
- Coinbase broker is the primary supported broker

## What Needs to be Added

### 1. Broker Type Enum (src/host/broker/mod.rs)
Add `mstock` to the broker types list, similar to how Coinbase is handled.

### 2. Credential Storage (src/service/keychain/broker_secrets.rs)
Add mstock secret key format and storage/retrieval methods.

### 3. BrokerHost Initialization (src/host/broker/mod.rs)
Add mstock to the list of brokers that BrokerHost can produce/manage.

### 4. Order Placement (src/workplace/trade/broker.rs)
Add mstock-specific order draft conversion and placement logic.

### 5. UI Integration (src/workplace/trade/sheet.rs)
Add mstock account selection and order submission UI.

### 6. MCP Integration (src/host/mcp/)
Add mstock-related MCP commands if needed for agent control.

## Implementation Pattern (based on Coinbase)

The existing Coinbase broker implementation in `src/host/broker/mod.rs` serves as the template:

```rust
// Example pattern from existing code
pub const COINBASE: BrokerId = BrokerId::new("coinbase");
```

Would need something similar:
```rust
pub const MSTOCK: BrokerId = BrokerId::new("mstock");
```

And connection handling following the same pattern as `COINBASE`.
